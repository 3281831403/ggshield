### Fixed

- `ggshield secret ignore --last-found` now faithfully reflects the scan that just
  ran. The `.cache_ggshield` file is anchored to the directory ggshield was invoked
  from instead of following the scanned repository (where it could appear as an
  untracked file); concurrent scan batches no longer wipe each other's recorded
  secrets, so every hit of the scan is cached; a scan that finds nothing now clears
  the stale cache instead of leaving the previous run's secrets in it (an empty
  scan still does not create the file); and a corrupted cache file now degrades to
  a warning instead of failing the command with exit code 128.
