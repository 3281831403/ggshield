### Added

- New `secret.fail_on_ai_hook_error` setting (default `false`), also available as the `GITGUARDIAN_FAIL_ON_AI_HOOK_ERROR` environment variable, decides whether `ggshield secret scan ai-hook` blocks an action it cannot scan: an unrecognized agent, a missing or unreadable token, an API error or a timeout. When `false`, the action goes through: a known agent shows that it was not scanned, while an unrecognized agent only gets a warning on stderr, which most agents do not display. When `true`, it is denied.

### Fixed

- `ggshield secret scan ai-hook` no longer exits 1 for an agent it does not recognize, which made the GitHub Copilot desktop app deny every tool call while other agents ran them unscanned without notice. It now follows `secret.fail_on_ai_hook_error`: exit 0 to allow, exit 2 to block.
